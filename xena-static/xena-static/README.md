# XENA portfolio: static version (HTML + CSS + JavaScript)

Open `index.html` in a browser, or host the folder on any static host (Netlify, Vercel, GitHub Pages).

- `index.html` page shell, loader, navbar, full-screen menu (with the colour-variant switch), footer
- `styles.css` all styling, including the "Indigo Night" colour variant (`html[data-theme="alt"]`)
- `app.js` routing (#work, #about, #contact), all page templates, project data, animations, cursor, menu, theme toggle, contact form
- `work/`, `logos/`, `*.mp4`, `*.webp` media

Where to edit: projects in `PROJECTS` (app.js), testimonials in `REVIEWS`, FAQ in `FAQ`, About pillars in `PILLARS`.
Replace `work/mock-tees.jpg` and `work/mock-chiaro.jpg` with real site screenshots if you like.
Fonts (Anton, Barlow Condensed) load from Google Fonts.
